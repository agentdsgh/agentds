# Правила проекта

- Язык документации и отчётов — русский; идентификаторы команд и кода — английские.
- Задачи GitHub ведём через навык `github-tasks`: `doctor` → `show` → правка → `status` →
  `commit` → `push` → `pr` → `report`.
- Секреты только в `~/.config/opencode/github-tokens.json` или env. В коде, issue и PR — плейсхолдеры.
- Не делать force-push, не удалять ветки, не мержить PR без явной просьбы.
- Коммиты: `type(scope): summary (#N)`, где `type` — `fix`, `feat`, `docs`, `refactor`, `test`.
- Перед PR обязательны проверки: тесты/линтер проекта, `python3 -m py_compile` для скриптов навыка.
- В отчёте разделять «Сделано», «Не сделано / ограничения», «Проверка».
- Не расширять скоуп задачи: побочные находки — отдельным issue.
- `archive/` не редактируется: это историческая реализация v1.
